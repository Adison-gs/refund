# 💸 Refund

Projeto desenvolvido durante um curso de desenvolvimento web, com foco na prática de HTML, CSS e JavaScript.

## 🔗 Demonstração

Acesse a aplicação: [Refund](https://adison-gs.github.io/refund/)

## 📋 Sobre o projeto

O Refund é um projeto web desenvolvido com o objetivo de praticar conceitos fundamentais do desenvolvimento front-end, incluindo estruturação de páginas, estilização e interatividade.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📂 Estrutura do projeto

```text
refund/
├── img/
├── index.html
├── script.js
├── styles.css
└── README.md
```

- `index.html`: estrutura da aplicação.
- `styles.css`: estilos da interface.
- `script.js`: lógica e interatividade.
- `img/`: recursos de imagem do projeto.


## 📚 Objetivo de aprendizado

Praticar os fundamentos do desenvolvimento front-end e compreender a integração entre HTML, CSS e JavaScript na construção de aplicações web.

Projeto desenvolvido para fins educacionais.
